# .github

Account-wide community health files for the KofTwentyTwo repositories
([K22-REPO-10](https://github.com/KofTwentyTwo/standards/blob/main/standards/repository.md)).
GitHub applies these defaults to every public KofTwentyTwo repository that does not
carry its own copy:

- [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md): Contributor Covenant 3.0.
- [SUPPORT.md](SUPPORT.md): where to ask for help and where to report security issues.
- [profile/README.md](profile/README.md): the account profile.

Issue and pull request templates stay per repository: they ask for product-specific
details (versions, logs, checklists) that do not transfer.
