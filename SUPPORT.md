# Support

Thanks for using a KofTwentyTwo project. Here is where to go for help.

| Need | Where |
|---|---|
| A question, a how-to, or an idea | The repository's **Discussions** tab (`https://github.com/KofTwentyTwo/<repo>/discussions`) |
| A bug or a concrete change request | The repository's **Issues** tab, using the issue templates |
| A security vulnerability | **Not** an issue or discussion. Use the repository's **Security** tab, then *Report a vulnerability* (private vulnerability reporting); each repository's `SECURITY.md` has the details and timelines |
| A code of conduct concern | See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

Before opening anything, search the existing issues and discussions: the answer is
often already there.

These are personal open-source projects maintained in spare time. Issues and
discussions are read regularly, but there is no guaranteed response time outside the
security process.
