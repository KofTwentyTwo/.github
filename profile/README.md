# KofTwentyTwo

Personal open-source projects by James Maes.

- [gclo](https://github.com/KofTwentyTwo/gclo): clone or update every repository of a
  GitHub organization in one pass (Windows 11 desktop app and CLI).
- [standards](https://github.com/KofTwentyTwo/standards): the engineering, security,
  and release standards these projects follow, including the shared GitHub Actions
  workflows.

Looking for help? See [SUPPORT.md](https://github.com/KofTwentyTwo/.github/blob/main/SUPPORT.md).
Security reports go through each repository's **Security** tab, never through a
public issue.
